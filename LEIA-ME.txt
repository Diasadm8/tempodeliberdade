GRUPO JOVEM TEMPO DE LIBERDADE · SITE

O QUE TEM NA PASTA
  index.html  -> os textos do site
  style.css   -> cores e visual (as cores ficam no topo do arquivo)
  script.js   -> palavras do título animado, lista de fotos e animações
  imagens/    -> logos
  imagens/galeria/ -> fotos da galeria

COMO COLOCAR AS FOTOS NA GALERIA
  1. Salve as fotos em .jpg dentro de imagens/galeria
     (nomes simples, sem espaço nem acento: foto43.jpg, foto44.jpg...)
     Prefira fotos com no máximo 1400 pixels de largura (~300 KB).
  2. Abra o script.js e, na lista FOTOS, escreva o nome de cada arquivo
     e uma legenda curta. A ordem da lista é a ordem no site.
  Para tirar uma foto, apague a linha dela da lista.
  O site mostra 12 fotos por vez; para mudar, altere FOTOS_POR_VEZ.

COMO TROCAR AS PALAVRAS DO TÍTULO ("Tempo de ...")
  Abra o script.js e edite a lista PALAVRAS, logo no começo.

COMO MUDAR UM TEXTO
  Abra o index.html, procure (Ctrl+F) o texto que quer mudar e escreva por cima.

COMO O SITE É PUBLICADO (GITHUB PAGES, GRÁTIS)
  O site fica num repositório do GitHub e é publicado pelo GitHub Pages.
  Configuração (feita uma vez só): no repositório, Settings > Pages >
  "Deploy from a branch" > branch "main", pasta "/ (root)" > Save.

COMO ATUALIZAR O SITE
  Depois de mudar qualquer arquivo, rode dentro da pasta do site:
    git add -A
    git commit -m "Descreva aqui o que mudou"
    git push
  Em 1 ou 2 minutos o GitHub Pages publica a nova versão.
  Também dá para editar direto no site do GitHub: abra o arquivo, clique
  no lápis, faça a mudança e clique em "Commit changes".
